# Система учёта заказов

Приложение для менеджеров интернет-магазина. Управление клиентами, товарами, заказами, аналитика, экспорт/импорт данных в CSV и JSON. Данные хранятся в Excel-файле (`.xlsx`). Проект выполнен в рамках итоговой аттестации по Python и использует только стандартную библиотеку Python — установка дополнительных пакетов не требуется.

## Установка и запуск

Для работы приложения требуется Python 3.8 или выше. Внешние библиотеки не нужны: используются только встроенные модули `tkinter`, `csv`, `json`, `zipfile`, `xml`. Если в системе установлен `matplotlib`, графики в окне аналитики будут строиться с его помощью; в противном случае графики автоматически рисуются на `tkinter.Canvas` — приложение работает в любом случае.

Склонируйте репозиторий или скачайте исходный код. В корневой папке проекта дважды кликните по файлу `run.bat` — это запустит приложение. Если вы предпочитаете ручной запуск, откройте терминал в папке проекта и выполните команду `python main.py`.

## Структура проекта

Проект организован следующим образом. В папке `src` находятся все основные модули: `models.py` с классами данных (`Entity`, `Client`, `Product`, `Order`), `xlsx_io.py` — собственный мини-модуль для чтения и записи Excel-файлов на основе `zipfile` и `xml`, `excel_db.py` — менеджер данных `ExcelDatabaseManager`, `gui.py` — графический интерфейс на tkinter, `analysis.py` — аналитика и построение графиков, `utils.py` — вспомогательные функции. В корне лежат `main.py` (точка входа), `run.bat` (запуск в Windows), `generate_test_data.py` (генерация тестовых данных), `requirements.txt`, `.gitignore` и `README.md`. Папка `data` содержит Excel-файл `orders.xlsx`, папка `screenshots` — скриншоты интерфейса, папка `tests` — юнит-тесты.

## Описание модулей

Модуль `models.py` содержит абстрактный базовый класс `Entity` и его наследников `Client`, `Product`, `Order`. Реализованы инкапсуляция через свойства, полиморфизм через метод `to_dict`, наследование от `Entity`.

Модуль `xlsx_io.py` — собственная реализация чтения и записи формата `.xlsx` без сторонних библиотек. Excel-файл — это ZIP-архив с XML-документами внутри, поэтому используется `zipfile` и `xml.etree.ElementTree` из стандартной библиотеки.

Модуль `excel_db.py` предоставляет класс `ExcelDatabaseManager`, который хранит клиентов, товары, заказы и позиции заказов на четырёх листах одного Excel-файла (`Clients`, `Products`, `Orders`, `OrderItems`). Реализованы все операции: добавление, удаление, чтение, поиск и очистка данных.

Модуль `gui.py` реализует главное окно на tkinter с тремя вкладками — Клиенты, Товары, Заказы. Интерфейс включает формы добавления, таблицы с данными, поиск клиентов по имени, фильтрацию заказов по дате, сортировку по дате и сумме (с использованием собственной рекурсивной быстрой сортировки), а также меню для экспорта и импорта CSV и JSON, очистки всех данных и вызова аналитики.

Модуль `analysis.py` содержит функции для анализа данных: `get_top_clients` возвращает топ-5 клиентов по числу заказов, `get_orders_dynamics` возвращает динамику заказов по датам. Функция `show_analysis_window` открывает отдельное окно tkinter с двумя графиками. Если установлен `matplotlib` — графики строятся им, иначе используется `tkinter.Canvas`.

Модуль `utils.py` включает функции `validate_email` и `validate_phone` для проверки email и номера телефона с помощью регулярных выражений, функции `export_to_csv`, `import_from_csv`, `export_to_json`, `import_from_json` для работы с файлами, а также функцию `sort_orders`, реализующую рекурсивную быструю сортировку с использованием лямбда-выражений.

## Тестирование

Для запуска юнит-тестов, которые покрывают модули `models.py` и `analysis.py`, откройте терминал в корневой папке проекта и выполните команду:
python -m unittest discover tests

При успешном прохождении всех тестов вы увидите сообщение `OK`.

## Генерация тестовых данных

Для быстрого наполнения базы данных случайными клиентами, товарами и заказами используйте скрипт `generate_test_data.py`. Он генерирует JSON-файл с фиктивными данными, который затем можно импортировать через меню приложения. Запустите скрипт командой:

python generate_test_data.py

После выполнения появится файл `big_data.json` в корневой папке. В приложении выберите в меню **Файл → Импорт из JSON** и укажите этот файл — данные автоматически загрузятся в Excel-файл. В начале скрипта находятся настройки: можно изменить количество клиентов (`NUM_CLIENTS`), товаров (`NUM_PRODUCTS`), заказов (`NUM_ORDERS`) и имя выходного файла (`OUTPUT_FILE`).

## Системные требования

Для работы приложения требуется Python 3.8 или выше. Дополнительные библиотеки не нужны: используются только стандартные модули Python. Если в системе установлен `matplotlib`, графики в окне аналитики строятся с его помощью — это улучшает внешний вид, но не является обязательным. Установка зависимостей не требуется.

## Хранение данных

Все данные хранятся в одном Excel-файле `data/orders.xlsx`, который создаётся автоматически при первом запуске. Файл можно открыть в Microsoft Excel, LibreOffice Calc или любом другом редакторе таблиц. Excel-файл состоит из четырёх листов:

- **Clients** — клиенты (`id`, `name`, `email`, `phone`, `registration_date`);
- **Products** — товары (`id`, `name`, `price`, `category`);
- **Orders** — заказы (`id`, `client_id`, `order_date`, `total_price`);
- **OrderItems** — позиции заказов (`order_id`, `product_id`, `quantity`).
